# Security

Do not post credentials, connection references, approval codes, account data, or raw session logs in public issues. Report vulnerabilities through this repository's private security reporting feature when available. Otherwise contact the service operator through the Cenmax AI console support channel and request a private reporting route.

Only the versions and checks in `QUALIFICATION.md` are qualified. Run the helper and all workers with the documented private credential directory. Untrusted nodes or tools running as the same operating-system user can access that user's files and memory.
